# ECommerceCsvImport — модуль импорта товаров из CSV

Производственная практика **ПП.02.01 «Технология разработки программного обеспечения»**
(ПМ.02 «Осуществление интеграции программных модулей», специальность 09.02.07 «Информационные системы и программирование»).

**Тема:** разработка модуля импорта товаров в электронный магазин из CSV-файлов
с хранением данных в коллекциях в памяти.
**Вариант индивидуализации:** 1 «Электроника» (доп. поля `brand`, `warranty_months`, `model_number`).

**Место практики:** АО «ЭР-Телеком Холдинг» (бренд «Дом.ру»). Тестовый каталог содержит абонентское оборудование,
которое продает компания: Wi-Fi роутеры (в том числе Дом.ру Wave Plus), ТВ-приставки Movix, камеры видеонаблюдения Omny,
устройства умного дома TP-Link. Цены и остатки в CSV-файлах условные.

## Возможности

Обязательные:

- чтение CSV-файла по пути (относительно `wwwroot` или полный путь на диске);
- построчный разбор CSV, преобразование строк в объекты `Product`;
- валидация обязательных полей и допустимых значений;
- список ошибок с номерами строк файла;
- хранение товаров в памяти (`InMemoryProductRepository`, singleton);
- страница импорта с таблицей результата и страница списка товаров;
- повторный запуск импорта без падения приложения (дубликаты пропускаются с ошибкой).

Дополнительные (п. 11.2 задания):

| № | Функция | Где реализовано |
|---|---------|-----------------|
| 1 | Загрузка файла через браузер | `ProductsController.Upload`, `Import.cshtml` |
| 2 | Поиск по названию | `ProductCatalogQuery.Apply` |
| 3 | Фильтрация по категории | `ProductCatalogQuery.Apply` |
| 4 | Сортировка по цене / остатку / названию | `ProductCatalogQuery.Apply` |
| 5 | Страница деталей товара | `ProductsController.Details`, `Details.cshtml` |
| 6 | Общее количество и общая стоимость | `ProductsIndexViewModel` |
| 7 | Экспорт списка в CSV (можно импортировать обратно) | `ProductCsvExporter` |
| 8 | Unit-тесты (xUnit, 31 тест по плану тестирования) | `tests/ECommerceCsvImport.Tests` |

| 10 | Разделители `,` `;` `\t` (определяются автоматически) | `CsvLineParser.DetectDelimiter` |

Также: автоопределение кодировки (UTF-8 или Windows-1251),
очистка списка товаров для повторной демонстрации.

## Технологии

C# 12, .NET 8, ASP.NET Core MVC, Bootstrap 5, xUnit, Git. Внешние библиотеки для CSV не используются —
парсер написан самостоятельно (поддержка кавычек и экранирования `""`).

## Запуск

Требуется [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

**Visual Studio 2022:** открыть `ECommerceCsvImport.sln`, выбрать проект `ECommerceCsvImport`
как запускаемый, нажать F5.

**Командная строка:**

```bash
dotnet run --project src/ECommerceCsvImport
```

Открыть адрес из консоли (по умолчанию http://localhost:5129). При запуске приложение само
импортирует файл `wwwroot/csv/sample_products.csv`, поэтому на странице «Товары» сразу видны 11 товаров.

Путь к файлу и включение автоимпорта задаются в `appsettings.json`:

```json
"Import": {
  "AutoImportOnStartup": true,
  "FilePath": "csv/sample_products.csv"
}
```

Чтобы проверить импорт вручную: «Товары» → «Очистить» → «Импорт» → путь `/csv/sample_products.csv`
(или любой файл из `/csv/test/`) → «Импортировать товары».

**Тесты:**

```bash
dotnet test
```

## Архитектура

```
CSV-файл / загруженный файл
   ↓
ProductsController  (принимает путь или файл, ничего не валидирует сам)
   ↓
ProductImportService  (определение кодировки) → CsvLineParser (поля)
   ↓  валидация + создание Product
InMemoryProductRepository  (List<Product>, singleton)
   ↓
ProductsController → Views (Import.cshtml, Index.cshtml, Details.cshtml)
```

Репозиторий и сервис зарегистрированы как **singleton**: данные живут в памяти между
HTTP-запросами и теряются только при перезапуске приложения (это допускается заданием).

## Формат CSV

```
sku,name,description,price,currency,category_name,stock,image_url,is_active,brand,warranty_months,model_number
1001,Wi-Fi роутер Дом.ру Wave Plus,Роутер Wi-Fi 6 AX3000 для квартиры,3990,RUB,Роутеры,25,/images/wave-plus.jpg,true,Дом.ру,12,Wave Plus AX3000
```

| Поле | Тип | Обязательность | Правило / сообщение об ошибке |
|------|-----|----------------|-------------------------------|
| sku | string | да, уникальное | «Поле sku не может быть пустым», «Артикул товара уже существует» |
| name | string | да | «Поле name не может быть пустым» |
| description | string | нет | — |
| price | decimal | да | > 0; «Поле price должно быть числом больше 0» |
| currency | string | нет | пусто → `RUB`, приводится к верхнему регистру |
| category_name | string | нет | пусто → «Без категории» |
| stock | int | да | ≥ 0; «Остаток на складе должен быть целым числом не меньше 0» |
| image_url | string | нет | — |
| is_active | bool | да | true / false / 1 / 0; «Поле is_active должно иметь значение true, false, 1 или 0» |
| brand | string | да | «Поле brand обязательно для варианта «Электроника»» |
| warranty_months | int | да | 0…60; «Гарантия должна быть целым числом от 0 до 60 месяцев» |
| model_number | string | нет | — |

Ошибки уровня файла: «Файл не найден», «Данные для импорта отсутствуют», «Неверные заголовки CSV»,
«Неверное количество полей в строке».

Принятые решения:

- **Дубликаты SKU** (внутри файла и с уже загруженными товарами) пропускаются,
  в результат добавляется ошибка — рекомендованный заданием вариант.
- Заголовки ищутся без учета регистра и пробелов, порядок колонок может быть любым,
  лишние колонки игнорируются.
- Номер строки — физический номер строки файла (заголовок — строка 1). Ошибки файла — строка 0
  (на странице отображается «—»).
- Все ошибки строки собираются сразу (проверка не останавливается на первой ошибке).
- Пустые строки пропускаются и не учитываются в «Всего строк».
- Пустые **необязательные** колонки в конце строки можно опустить (например, без `model_number`);
  если не хватает обязательных колонок или полей больше, чем в заголовке, — ошибка
  «Неверное количество полей в строке».
- Цена принимается с точкой или запятой (`1290.50`, `"1290,50"`).
